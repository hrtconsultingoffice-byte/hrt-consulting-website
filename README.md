# HRTコンサルティング

Next.js App Router、TypeScript、Tailwind CSSで制作した5ページのWebサイトです。

## ローカルで確認する

Node.js 20.9以上を使用してください。プロジェクトのディレクトリで以下を実行します。

```sh
npm ci
npm run dev
```

ブラウザで http://localhost:3000/ を開きます。本番ビルドは `npm run build` です。

## Vercelで公開する場合

このディレクトリをVercelプロジェクトのルートに指定し、Next.jsプリセットを選びます。公開用ドメイン確定後に、canonical URLやSNS共有用URLを設定してください。

ナビゲーションから HOME、ABOUT、SERVICE、WORKS、CONTACT を開けます。事業者の所在地は掲載準備中です。CONTACTのフォームは入力内容をメールアプリに引き継ぎ、利用者が送信します。
